# New Map Autoclear

매크로가 없는 처음 보는 Geometry Dash 레벨을 분석해 입력을 스스로 만드는 자동 클리어 프로그램을 위한 작업 공간입니다.

아직 실행 가능한 자동 플레이 프로그램은 없습니다. 먼저 쉬운 Classic 큐브 레벨에서 안전하게 실험한 뒤 지원 범위를 넓힙니다.

## 개발 방향

화면의 그림만 보고 즉시 누르는 방식보다, Geode 모드가 레벨의 오브젝트와 플레이어 상태를 읽고 다음 입력을 계산하는 방식을 우선합니다. 화면 인식은 게임 내부에서 필요한 정보를 얻을 수 없을 때만 보조 수단으로 검토합니다.

처리 과정은 다음 네 단계로 나눕니다.

1. 레벨 오브젝트, 게임 모드, 속도, 중력과 플레이어 상태를 읽습니다.
2. 위험 구간과 착지 가능한 구간을 작은 내부 모델로 만듭니다.
3. 짧은 구간별로 점프 입력을 탐색하고 실패하면 다른 입력을 시도합니다.
4. 찾은 입력을 같은 레벨에서 재생하고 실제 결과와 비교합니다.

## 첫 번째 개발 목표

- Classic Normal 모드와 기본 큐브만 지원합니다.
- 테스트용 짧은 로컬 레벨의 장애물 위치를 읽습니다.
- 현재 상태와 읽은 장애물 정보를 파일이나 Geode 로그에 기록합니다.
- 저장 파일이나 최고 기록을 직접 수정하지 않습니다.

이 단계가 확인된 뒤 물리 시뮬레이션과 입력 탐색을 추가합니다. 비행선, 웨이브, 듀얼, 랜덤 트리거와 온라인 리더보드는 초기 범위에 포함하지 않습니다.
